# E-Portfolio (DCIT 26 Midterm Laboratory)

Built with React, Vite and Tailwind CSS. Theme: aurora purple, one long page with a big hero and scroll animations.

## Run locally
    npm install
    npm run dev

## Before you submit
1. Open `src/data.js` and replace everything marked `UPDATE` (last name, email, social links, project links, education and experience).
2. Rename this folder to your last name (example: `delacruz-portfolio`).

## Deploy on Vercel
1. Push the folder to a GitHub repository.
2. On vercel.com choose "Add New > Project" and import the repository.
3. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
4. Click Deploy, then open the Vercel URL and test every section.
